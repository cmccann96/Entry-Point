# Data directory

Place the operator-supplied sold-sales export here as `sold_sales.csv`.

This file is **not** committed (see `.gitignore`) and is **not** generated by any
code in this repository. The harness will not run without it, and will not
substitute anything for it.

Obtain it from eBay Seller Hub → Research (Terapeak) → export. See the
"Data sources" section of the top-level README for the required columns and for
why this is the only compliant Stage 1 input.
